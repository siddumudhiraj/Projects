# Skyline Weather

Weather app built with Angular 22. Search a location or use your current position to see the current conditions and a 48 hour outlook.

## Setup

Add your Visual Crossing API key in `src/environments/environment.ts` (get one at visualcrossing.com/weather-api).

## Run

```
npm install
npm start
```

Open http://localhost:4200

## Build

```
npm run build
```
